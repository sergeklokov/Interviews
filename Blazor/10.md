# Blazor 100 Questions, Answers, and Unique Code Examples

## What is Blazor?

Blazor is a .NET web UI framework that uses C# instead of JavaScript.


```csharp
<h3>@message</h3>
@code {
    string message = "Hello from Blazor!";
}
```


---

## What hosting models does Blazor support?

Blazor supports Server and WebAssembly hosting models.


```csharp
// Program.cs
builder.Services.AddServerSideBlazor();
builder.Services.AddWebAssemblyHostBuilder();
```


---

## What is a Razor component?

A Razor component is a .razor file that combines HTML and C#.


```csharp
<!-- Counter.razor -->
<h3>Counter</h3>
<p>@count</p>
<button @onclick="Increment">+</button>

@code {
    int count = 0;
    void Increment() => count++;
}
```


---

## How do you perform data binding in Blazor?

Data binding in Blazor uses @bind for two-way binding.


```csharp
<input @bind="name" />
<p>Hello, @name!</p>

@code {
    string name = "";
}
```


---

## How do you navigate between pages in Blazor?

Navigation is handled with @page directive and NavigationManager.


```csharp
@page "/home"
@inject NavigationManager Nav

<button @onclick="Go">Go to About</button>

@code {
    void Go() => Nav.NavigateTo("/about");
}
```

## How do you inject services?

Services are injected using @inject and configured in Program.cs.


```csharp
@inject TimeService TimeSvc
<p>The time is: @TimeSvc.Now</p>
```

## How does JavaScript interop work?

JavaScript interop uses IJSRuntime to call JS functions.


```csharp
@inject IJSRuntime JS
<button @onclick="ShowAlert">Click</button>

@code {
    async Task ShowAlert() {
        await JS.InvokeVoidAsync("alert", "Hello from JS!");
    }
}
```


---

## How do you call C# from JavaScript?

C# methods can be invoked from JavaScript using JSInvokable.


```javascript
// site.js
window.triggerDotNet = function(obj) {
    obj.invokeMethodAsync("OnTriggered");
}
```
```csharp
@inject IJSRuntime JS
<button @onclick="CallFromJs">Call C# from JS</button>

@code {
    async Task CallFromJs() {
        var obj = DotNetObjectReference.Create(this);
        await JS.InvokeVoidAsync("triggerDotNet", obj);
    }

    [JSInvokable]
    public void OnTriggered() => Console.WriteLine("JS called C#");
}
```

## How do you validate forms in Blazor?

Blazor uses EditForm and validation attributes for validation.


```csharp
<EditForm Model="@person" OnValidSubmit="Save">
    <DataAnnotationsValidator />
    <ValidationSummary />

    <input @bind="person.Name" />
    <button>Submit</button>
</EditForm>

@code {
    Person person = new();
    void Save() => Console.WriteLine(person.Name);
}
```

## What is a cascading parameter?

Cascading parameters allow passing values down the component tree.


```csharp
<!-- Parent.razor -->
<CascadingValue Value="Theme">
    <Child />
</CascadingValue>

@code {
    string Theme = "Dark";
}

<!-- Child.razor -->
@code {
    [CascadingParameter]
    public string Theme { get; set; }
}
```
